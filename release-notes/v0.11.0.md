# Engineering Assurance v0.11.0

This release adds human-gated feature risk rating and expands signed approval,
proof, and release evidence verification.

## Highlights

- Added a feature risk rating workflow with explicit human acceptance.
- Added proof checkpoint verification and signed receipts for approval and
  release tags. Receipt verification detects missing, changed, and deleted
  tags.
- Strengthened signature verification with trusted signing time, reproducible
  signer identity, committed identity-to-person mappings, and interactive
  signing gesture evidence.
- Added producer build identity and generation time to command results.
- Added a real-tool test lane and documented private vulnerability reporting.
- Release decision output now presents the risk summary, overall evaluation,
  and risk management review.

## Known anomaly

The `ci.yml` verification workflow runs only when manually dispatched. It does
not run automatically for pushes. The reusable Release attestation workflow
does not by itself configure a tag trigger or enable release tag attestation.

The US and EU clause packs are not published to npmjs.
