## Verdict

FAIL (one high). The exact-object binding is correctly added: verified requires signed_valid with a mapped signer, resolved tag_object_id equal to expected.tag_object_id, and all fields matching; CON-3 and AC-9 make the same-fields/different-object case refuse; FR-080 still states that verified is not FR-041 approval (CON-2, AC-8). FR-040's tag/commit contract keeps the commit path unchanged and moves only the tag path into the snapshot; FR-041 maps snapshot refusal to unverifiable; TC-279 and TC-1011 agree with FR-040-AC-2 and FR-041-AC-23/25. EA-132 remains spec-only (no verifier, no retention provider). TC-1017 is unchanged and remains the EA-129 open anomaly; it is context only. PR #295 code was not reviewed or accepted here.
