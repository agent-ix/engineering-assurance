# Content rights

This private repository contains original Agent IX implementation,
configuration, and fictional test material. The project license applies only to
content Agent IX is entitled to license.

Allowed tracked content is limited to:

- original source code and configuration;
- fictional schemas, templates, and tests;
- dependency metadata;
- the project license; and
- concise operating documentation written specifically for this project.

Do not commit external prose, rule or clause inventories, applicability
matrices, crosswalks, legal-review material, research files, operational
evidence, workstation locations, or encoded copies of excluded material.

The automated check is necessary but not sufficient. Every release candidate
also requires a semantic review of the complete staged tree and built packages.
